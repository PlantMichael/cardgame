## Outcome and scope

Create the public-facing `cardgame` home, rulebook and searchable keyword glossary on the existing Vercel project. Home should introduce the actual game, show existing card art and five named factions, offer meaningful learning links and a prominent Play action. The Godot game remains the same export, launched directly at `/play/`; the site does not download the engine on landing. Root becomes the website as requested. Learn routes are independently linkable, usable without JavaScript, responsive and keyboard accessible. Glossary search adds live filtering/count, clear and empty states; terms have stable fragment anchors. Use a light scripting layer and native HTML/CSS; no new framework/dependency, accounts, backend changes, statistics dashboard, telemetry, game rules or Godot regeneration. Do not invent unsupported player counts, testimonials, release claims or game features.
