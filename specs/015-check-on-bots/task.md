## Grounded shape

The relay already owns the ranked queue (`server/relay.js:272`), verified session/command routing (`:443`, `:528`, `:953`), disconnect/ping lifecycle (`:1082`) and authoritative sessions (`server/authoritative/match_manager.js:91`). Rank comes from persisted player fields and canonical settlement (`server/ladder.js:35`), not from hidden matchmaking Elo. Reuse these owners: no worker heartbeat table, polling the hosting provider, history log or new database schema.

Add a narrowly scoped anonymous `GET/HEAD/OPTIONS /data/bots/status.json` on relay and catalog. The relay reads only the four server-owned mappings and current visible rank fields, returning a timestamp and exactly Io, Callisto, Europa and Ganymede with their public profile, activity and rank (null if not provisioned). Track verified active socket bindings in the relay's existing authentication paths and remove them on disconnect/logout/failed rebinding; never remember a socket after it closed during an awaited query. Derive activity from current socket presence, normal queue membership, in-flight pairing and active manager sessions. States distinguish queued, joining, playing, between matches, reconnecting, offline and not started. Finished session tombstones cannot imply playing; host-down/disconnected seats cannot imply a healthy active game. Existing 30-second ping/termination owns dead-transport detection, so this is the relay's latest known state rather than instantaneous process telemetry.

The callback and mapping remain internal; the public API accepts no player selector and exposes no player IDs, session tokens, hidden Elo, human opponent names, match IDs, cards, commands or seeds. Only the four owned bots' visible ranks become public. Query errors return 400, unsupported methods 405, unavailable data 503. Read rank and activity into one bounded snapshot; coalesce/cache successful relay snapshots for five seconds, never cache a failure as offline. The catalog uses the established public projection, no redirects, five-second timeout, a small bounded body and explicit four-identity/rank/activity validation. All HTTP status responses use no-store; no stale data is presented as current after an error.

Add `/stats/bots/`, linked as “Check on the bots” from every Statistics view, and a link back to Statistics. Four compact cards show name, v1.0/playstyle/level context, activity and the real named rank plus LP (or Legend band/points). Reuse existing rank icons and `website/ranked-data.mjs` division/Legend definitions, shipping that module to the client rather than inventing another ladder. Reuse the current sci-fi shell, typography, borders and colors. Use two columns on desktop, one on phones. This is a read-only page with an explicit last-check time, manual refresh and automatic ten-second refresh while visible. Loading/unavailable states retain all four identities with unknown activity/rank, offer retry and do not invent offline/rank values. Stop hidden-page polling, abort superseded requests and prevent a slower old response from overwriting a newer one. No new control panel actions or services.
